## 2026-10-11: Found a healthy reply answering the wrong question
**Learned.** My daily recap counts the email I sent each day by asking a Google Apps Script endpoint to search my sent mail, and on Wednesday that request came back with an ok status three times in a row and no threads at all. Each reply was the endpoint's health check, the answer it gives to a plain ping, so the search had reached the server and returned a response to a question nobody asked. A run that trusted the status would have reported zero emails sent, so that run called the read failed, left the count blank, and filed the defect to my maintenance outbox. On Sunday my maintenance sweep made the read require an actual search result carrying a list of threads, so the same reply now retries three times and then fails loudly, and it verified the fix against a live day of 12 threads, a live empty window that still passes, and a simulated health-check reply that gets rejected; why the search sometimes lands on the health check is still open, because the endpoint behaved on the day of the fix. A status field tells you the server answered, and only the shape of the payload tells you which question it answered.

## 2026-10-07: Moved the fabrication check out of the reviewer and into a script
**Shipped.** On Tuesday an agent updating one of my interview prep guides wrote six stories into my draft answers that never happened, including a pricing decision I never made, a design-doc debate that never took place, and a line claiming I review pull requests, and my independent reviewer passed the guide anyway; my orchestrating session caught them only by searching my source documents by hand. On Wednesday I built `verify_guide.py`, which checks every first-person claim in a guide against my career history, story bank, resumes, and my own side of labeled interview transcripts. Matching single words was useless, because those sources run about 20,000 words and nearly any word appears somewhere, so the script requires a claim's numbers, names, and two-word phrases to be supported within one source passage; its first test caught only four of six reconstructed fabrications because a case-sensitive pattern skipped every sentence starting with "We," and after calibration it cut the live guide from 21 flags to 3, all three real. Every flag now gets fixed with a placeholder asking me for a real example, and the rules forbid rewording a story until it passes. Since I approved the wiring on Friday, the check runs before the reviewer in both skills that produce guides, and the agent that drafts them carries a matching grounding rule. A reviewer is good at reading the page in front of it and bad at proving something is absent from six other files, and a lookup like that belongs in code.
