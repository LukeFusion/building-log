# building-log

A running log of what I build, learn, and decide. Product systems, AI agents, small apps, automations.

I'm a product leader who builds. This is the working record: short entries, timestamped, newest first. Not a blog, a log.

## Structure
- One file per month under `2026/`
- Newest entry at the top of each file
- Three kinds of entry: **Shipped** (made a thing), **Learned** (figured something out), **Decided** (made a call and why)
